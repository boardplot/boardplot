# Changelog

Boardplot is in 0.x: options and output can change between minor versions. Each release lists its changes here.

## 0.54.0

### Added

- The docs page `docs/use-cases.md` shows how to use Boardplot with an AI agent such as Claude Code or Codex: install and check, then one section each for a PowerPoint or Keynote deck, an analysis page or Claude artifact, a React dashboard, a Word or PDF report and a recurring report. Each section gives example prompts, what the agent does with the Boardplot tools or components, tips and limits. The README, the manual, `llms.txt`, the npm package and the offline plugin ZIP link or carry it, and the chart skill says what to do for each destination.

### Changed / may need action

- A spec or theme that uses a setting Boardplot once accepted draws again. A renamed setting draws as its successor, and a removed one is ignored. Both warn `option-deprecated` with a JSON Patch that rewrites or removes it, on the CLI, the MCP tools, React, `parseThemeJson` from `boardplot/validate`, theme objects and theme overrides. Before, each of these settings was refused and the chart did not draw. A key that never existed is still refused. These settings draw again:
  - Theme keys, ignored: `space.barGap`, `type.eyebrow.case`, `chrome`, `motion.update`, `motion.exit`. `table.weights.change` keeps drawing and now stays accepted for good.
  - Theme presets: `ibcs` draws as `notation` and `ibcs-dark` as `notation-dark`. `consulting` and `legacy-glass` draw as `boardroom`.
  - Palettes `garnet` and `heritage`: the theme's own series draw, as before. The warning is now `option-deprecated` with a fix that removes `options.palette`, in place of `unknown-palette`.
  - Option renames: waterfall `orient`, funnel `layout`, heatmap `glyph`, cohort `exhibitStyle`, diagram `preset`, waffle `fillMode` and treemap `shape` draw as `variant`. Variance `variance.mode` draws as `variant`. Mekko `mode: 'percent'`, `'unit'` and `'bar'` draw as `variant: 'stacked100'`, `'stacked'` and `'bar'`. Table `preset` draws as `variant`, and `preset: 'plain'` as `variant: 'hierarchy'`. Dimswitch `structure: 'byMeasure'` and `'byMember'` draw as `variant: 'by-measure'` and `'by-member'`. Bartable `cascade: true` draws as `variant: 'cascade'`, and `panelScale: 'own'` and `'shared'` as `sharedScale: false` and `true`. Grid `share: 'categories'` and `'none'` draw as `sharedAxis: 'category'` and `'none'`. Combo `labels.growth` draws as `dualAxis.growth`.
  - Value renames: line `variant: 'stackedArea'` and `'area100'` draw as `'stacked-area'` and `'stacked100-area'`. Dimswitch `order: 'authored'` and treemap `order: 'data'` draw as `'sheet'`. Choropleth `pack: 'de-laender'` draws as `'de-states'`.
  - Options, ignored: `strings.highlight` (in the React theme provider's strings it is ignored without a warning), `target: 'legacy'`, dimswitch `preset` and `density: 'cohort'` and `'cohort-small'`, line and combo `lineLabels` and `endpointLabelDefault` (use `seriesLabels` and `valueLabels`), column, line and combo `eventLegendFootnotes`, line, combo and grid `hover`, pareto `ruler`, pvm `effectOrder`, grid `gap`, `gutterWidth`, `showMaturing` and `totalPanel`.
  - Data fields, ignored: category `total100` on dot, butterfly, slope, variance, pie, heatmap and funnel; category `gapAfter` and `breakAfter` on those types and mekko; series `direction` on line, combo, slope and butterfly; series `role` on butterfly and heatmap; series `fill` on pie and heatmap; diagram port `priority`.
  - The same applies inside the panels and the repeat template of a grid.
- Gantt and grid-level `options.format` stay accepted and ignored with their `format-unused` warning. The warning no longer says that the next release refuses them.

### Fixed

- A React chart that gets `rows` draws in a Vite 8 production build. Before, it stayed on the busy placeholder: Rolldown wrote the rows chunk as an empty file, because the chunk published the rows transform only through a module-scope call and `sideEffects` did not list it. The rows chunk, the annotation engine and the patched-theme checks now load through the exports of their chunk, which no bundler drops. A chunk that loads and still publishes nothing shows the load-failure card instead of the busy placeholder. No golden changes.
- Line end labels at the last category use one form. Before, two lines that ended close together printed "Name value" in the label column, while a line that ended apart printed its value over its endpoint and its name alone in the column, so the reader saw two labels for that one series. Now, once one end label takes its value, every end label at the last category does. When the joined labels do not fit, all of them fall back together, as before: values at their points, names in the column. Lines that end before the last category, area and stacked variants, fans and bump charts are unchanged. Ten line goldens change (both themes): `multiline-highlight-fade`, `ordered-ramp-rest-apart`, `peer-regions-ramp`, `regions-ramp-target`, `shared-trajectory-milestones-1` to `-3`, `shared-trajectory-review-1` and `-2`, `trajectory-highlights`.
- A neutral grey in a theme no longer warns `accent-reads-as-loss`. Before, a grey `neutralMark`, `highlight`, `focus`, `total` or first series near a muted red-brown `bad` colour warned, because a grey has no OKLCH hue and the check fell back to RGB distance under 90. A colour with OKLCH chroma under 0.02 now counts as grey and skips that fallback. A muted warm accent near a muted `bad` still warns. No golden changes.
- A full theme whose `color.series` has one or two colours draws. Before, it was refused with `invalid-theme` ("expected array to have >=3 items"), so a brand theme for a two-series chart had to add an unused third colour. A series past the end of the ramp follows `color.seriesOverflow`, as before. No golden changes.
- The event lane of line, column and combo charts fits more events as text blocks. Before, an event whose pole grazed the end of an earlier block fell back to a numbered marker with a key entry, even when the lane had a free row. The lane now turns one placed block to the other side of its pole when that frees room for the next event. Golden changes: `column/weekly-events-lane` and `combo/weekly-events-lane` (both variants) draw the 26 Aug launch in the lane instead of key entry 4, and the 10 Aug block turns left of its pole.

## 0.53.0

### Added

- Gantt takes `options.calendar`. `calendar.weeks: 'startDay'` names each week cell by the day of the month it starts on ("9"), flush left under the month tier, in place of the ISO week number ("W11"). It applies at week granularity only; elsewhere it is ignored with the info lint `calendar-weeks-ignored`. `calendar.span: 'data'` runs the timeline from the first item to the later of the last item end and `today`, in place of whole calendar periods, so arrow tips meet the edge. The head's scale follows that span. A milestone or cadence marker on the first or last day keeps room for its radius (up to 8 px) inside the edge, at any width. Weekend bands count from the Monday on or before the span start. The defaults (`'isoWeek'`, `'periods'`) keep the current head. The `status-timeline` fixture uses both.
- Gantt `rows[].sublabel`: a second line under the row name, such as what the row measures. It prints in the label font and muted ink, on one line and never cut. The name band takes the wider of the name and the sublabel, and the name and sublabel centre together on the row. On narrow canvases (the stacked form) it follows the name on the row's name line. `labels.activity: false` hides it with the name. A row whose wrapped name and sublabel need more than the row pitch grows to fit them. The accessible row summary and the item and cadence event records read "name, sublabel". New example fixture `status-timeline`.
- Gantt items take `kind: 'rule'`: a quiet span for the state before a change. It draws a 2 px neutral line on the bottom edge of the bar box, with its label 2 px above the line in muted ink, flush left. The line is a data mark and never breaks around text. A rule never takes a colour or a colour-key entry; `colorRole` or `colorLabel` on a rule is refused. The `status-timeline` fixture uses it for the states before each change.
- Gantt events take `labelPlacement: 'badge'`: the label, at most 3 characters such as a change number, sits in a filled circle at the top of its rule, and the rule starts 2 px under the circle. The circle is ink, or the bad colour for `tone: 'bad'`. Its text takes the ink that reads on the circle in the active theme. Badges stack in their own strip above the event names, numbered rings and today label, so adding a badge hides none of them. Without annotation labels no badge is drawn and the strip takes no height. Badge events never go to the numbered footnote key and do not count toward the key mode above three events. Badges closer than their width plus 4 px stack one level up. A longer badge label is refused, and column and combo refuse `'badge'`. The `status-timeline` fixture numbers its three changes with badges.
- Rows for `table` (alias `tbl`): `boardplot render` and `boardplot measure` with `--rows`, `boardplot_render` and `boardplot_measure` with `rows` or `rowsFile`, and `specFromRows` from `boardplot/rows` fill `data.rows` from a flat table, one source row per table row. The spec's `data.columns` declares the columns, with no inference from the rows: each `value`, `text`, `status` or `date` column reads the source field named like its id, and `computed` and `encoding` columns keep their definitions. Two optional column roles: `label` fills the row label that the `rowLabel` column shows, and the new role `id` fills the row id (default `row-1`, `row-2`, ...), as in `--columns label=region,id=code`. Rows keep source order. A spec row with the same id keeps its authored fields, such as `role`, `parentId`, `calc` or `format`. A table column with no source field, text that a value column cannot read as a number, a boolean cell, an empty or repeated row id and a `valueKind` other than `number` are refused with the source row and field; a refusal or warning of the table engine about a source cell, such as a status it refuses, names the source row and field too. A repeated spec row id, a nested spec row with another `parentId`, and a drawn row whose `parentId` or `calc` names a spec row that no source row provides are refused at the spec field.
- Rows for `histogram` (aliases `distribution`, `frequency`) and `box` (aliases `boxplot`, `box-and-whisker`) in `boardplot render` and `boardplot measure` (`--rows`), `boardplot_render` and `boardplot_measure` (`rows`, `rowsFile`) and `specFromRows`: one source row per observation. Histogram takes the role `value`. Box takes `category` (the group id) and `value`, and optionally `categoryLabel` and `date`; groups keep their first appearance, and a group the spec already names keeps its other fields. A null, blank, non-numeric or non-finite observation is refused with `missing-value` or `invalid-value` and its source row and field, never dropped; a group with two labels or two dates, a group label or date that is not text (`invalid-value`) and a repeated spec group id (`invalid-data`, at the spec path) are refused; `valueKind` other than `number` is refused. A histogram still needs four observations.
- React: `onRowSelect(rowId, { row, event, columnId })` and `isRowSelectable(row, { collapsed })` on `BoardplotChart`, as `TableChart` takes them: a click in a table row or Enter or Space on its focused cell calls `onRowSelect`. Only a `table` spec (alias `tbl`) receives them; `BoardplotChart` passes them to no other chart type, so they never reach a chart's options. A `dimswitch` spec draws as SVG in `BoardplotChart` and takes no row pick; `DimSwitchChart` from `boardplot/react/dimswitch` keeps its own `onRowSelect`.
- React: `onSpecError(errors)` on `BoardplotChart`. It is called after commit with the findings `SpecErrorCard` shows, for an invalid spec or setting and for a chunk that did not load (`chunk-load-failed`), so a host no longer looks for the card in the page. It is called once per distinct set of findings: a rerender with the same findings, a host that sets state from the call, and StrictMode's repeated effects call it no second time. It is called once with `[]` when a later valid spec replaces the error card (its chart engine is ready, or its data is empty), without waiting for the chart to draw, because a valid spec can still wait for its container or refuse its size. Empty data stays on `onEmpty`, and a layout refusal on `onRefused`.
- Boardplot for Python in `python/`. `bp.chart(df, ...)` draws the same SVG as the CLI in a notebook or a script without Node, and `bp.st_chart` draws a chart in Streamlit. It is not on PyPI yet.

### Changed / may need action

- Gantt event rules and the today line give way to span names. A bar, arrow or shade name that has no seat clear of the rules now sits inside its own mark across them, and each crossed rule breaks over the full height of that mark. A seat clear of every rule still wins; each crossed rule adds 1 to a seat's penalty. Before, the rules blocked these names, which went to the notes list, so a long arrow name across two event rules was hidden below about 1,800 px. There is no option to bring the old behaviour back: it only ever hid labels. Milestone and bracket labels keep the rules as obstacles. The today line now keeps 2 px instead of 1 px above and below a label it breaks for (`torture-long-labels`).
- `gantt-arrow-label-hidden` suggests "increase chart width or shorten the arrow name". Height never gave an arrow name room.

### Fixed

- Percent cells (`{ pct }`, `valueKind: 'percent'` or `'fraction'`) keep their percent sign on bar, dot and funnel value labels ("70%", not "70"), as on column. This covers the centered funnel and a bar's Rest built from percent cells. A value axis whose values are all percent cells prints "%" on its ticks too, on line, column, bar and dot. An authored `format` on the chart, series or cell keeps winning; `options.format: '0'` brings back the bare numbers.
- A percent mekko of authored shares with no amount in the column (no number cell, no `total100`) prints no column total. Before, it printed "0" above segments that read 70% and 30%. The totals row, the `derived.columnTotals` entry and the totals sentence of the description leave such a column out. Number cells keep their totals.
- A `bartable` draws from rows (CLI `--rows`, MCP `rows` and `rowsFile`, `specFromRows`). Before, it was refused with `invalid-data` at `/data/panels`. The categories become the table rows, the series the bar segments, and the value column fills one panel. The spec's first panel is the template for that panel. Its `ends`, other panels and number `columns` are dropped, because they hold one value per authored row. Percent values fill the panel as plain numbers with the unit `%`. One panel adds its segments, so rows with two units, percent values beside plain numbers, or a value cell with more than its number (such as a `format`) are refused at their row.
- Data ids named like `Object.prototype` members (`__proto__`, `constructor`, `toString`, `hasOwnProperty`, `valueOf`) draw like any other id. Before, a category, series, stage, slice or column with such an id printed wrong values (`n.m.`, `+n/a`, a missing table cell, "on target" instead of the real gap), dropped box ticks and labels, or refused with a wrong cause (waterfall `label-collision`, pie `invalid-size`, pareto `invalid-number`). Keyed values such as table `cells`, bartable `values`, pie `explode`, dimswitch `sums` and grid `bySlice` now keep a `__proto__` key, and a grid repeat value `__proto__` is no longer refused. Detail keys still refuse `__proto__`.
- Gantt `rows[].cols`: a cell object's `tone` is optional, so `{ "text": "x" }` is valid and means the same as `"x"`. Before, it was refused with a missing-tone error.
- Schema errors of a union with a literal tag: when one branch fails on its own tag (a gantt task row checked against `kind: 'cadence'`) and another branch has no error at that tag and fails on a field that is present, only the second branch's errors are reported. A branch that only misses a field never hides another branch's errors. Identical errors (same path and message) are reported once. Before, a task row with one bad item kind reported the item error plus a misleading "expected cadence" error, and a bad `cols` cell was reported twice. No golden changes.
- Gantt event rules at an ISO date or at a bar, chevron, bracket or shade item draw on the start edge of their day. An event at an item id now sits exactly on that item's start edge, the boundary it marks. Before, the rule sat half a day inside the new span. An event at a milestone or a cadence event keeps drawing through the middle of its marker. The today line stays at the middle of its day. No golden changes: the only fixture with events anchors them at cadence events.
- Text measurement gives default-ignorable code points (soft hyphen U+00AD, zero-width space, ZWNJ and ZWJ on their own, word joiner U+2060, BOM U+FEFF) no width and no letter-spacing step, with the bundled tables, host tables and the character-class model alike, also when a combining mark follows one. Browsers draw them invisible. The Hangul fillers (U+115F, U+1160, U+3164, U+FFA0) and the shorthand format controls (U+1BCA0 to U+1BCA3) keep their width, as browsers draw them. Wrapping keeps a BOM inside its word instead of breaking there as at a space. Before, a host table could give a soft hyphen a width, and `boardplot fonts build` wrote a negative variable-font advance as about 65 em, so a label with a soft hyphen measured far wider than it drew. `fonts build` now writes a negative advance as 0; rebuild host tables made with an earlier version. No golden changes.
- Number format examples and `rgba()` alpha colours no longer slow down on long malformed input. A format of 50,000 characters took 1 to 2 seconds to parse, and a chart parses its format about 16 times per render. Valid formats and colours parse to the same result.

## 0.52.5

First public release.

- 37 chart types from one JSON spec, among them bar, column, line, waterfall, mekko, scatter, tables, Gantt charts and maps.
- Output as deterministic SVG, as PNG and as React components; the same spec gives the same SVG, byte for byte.
- One collision solver places every label. A chart that does not fit is refused with the size it needs.
- Totals, differences, shares and growth rates are computed from the data, and each render reports them.
- Four targets (`report`, `dashboard`, `slide`, `print`) set the type sizes for the medium.
- Theme presets, custom themes and contrast checks; width tables for Geist, Helvetica and Arial (Helvetica Neue is measured with the Helvetica widths), and `boardplot fonts build` for a licensed font.
- Map packs for the world, Europe, the EU-27, the US states, the DACH countries and the German states.
- The `boardplot` CLI and the `boardplot-mcp` server with six MCP tools: list, describe, fixtures, measure, render and feedback.
- A plugin for Claude Code and Codex with a chart skill and the bundled runtime.
- Complete example specs (fixtures) for every chart type.
