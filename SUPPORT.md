# Support

- Questions and ideas: [GitHub Discussions](https://github.com/boardplot/boardplot/discussions).
- A bug: [open an issue](https://github.com/boardplot/boardplot/issues/new/choose) with the spec that shows it, the Boardplot version and the command, MCP tool or component you used.
- A security problem: report it privately, as [SECURITY.md](SECURITY.md) says.

Before you ask, look at the [manual](docs/manual.md), the [chart reference](docs/reference/) and the [gallery](docs/gallery.md). `npx boardplot fixtures --type <type>` prints complete example specs.
