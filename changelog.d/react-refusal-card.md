### Fixed

- A bad value in a React chart no longer unmounts the host's whole React root. An axis bound that is not a number, a size written as text, a theme name that does not exist or a geo pack that is not registered threw while the chart rendered, and the good charts beside it disappeared. The chart now draws the refusal card with the code and fix of the CLI refusal, such as `unknown-theme`, `invalid-size` or `geo-pack-not-registered`, and draws again when the props are fixed. A numeric string axis bound still draws as before. A choropleth without its pack draws that card where it used to throw, and `GeoPackNotRegisteredError` is now a `NormalizeError`. A hole in a sparse `values` array now reads as a missing value, as the `null` of a JSON spec does, where it threw `Cannot read properties of undefined`.
