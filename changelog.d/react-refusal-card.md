### Fixed

- Four kinds of bad value in a React chart no longer unmount the host's whole React root. An axis bound that is not a number, a size written as text, a theme name that does not exist or a geo pack that is not registered threw while the chart rendered, and the good charts beside it disappeared. The chart now draws the refusal card with the code and fix of the CLI refusal, such as `unknown-theme`, `invalid-size` or `geo-pack-not-registered`, and draws again when the props are fixed. A numeric string axis bound still draws as before. A table, a dimension-switch table and a table inside `BoardplotChart` draw the same card for a theme name that does not exist, a theme override that is not valid or a size written as text. A choropleth without its pack draws that card where it used to throw, and `GeoPackNotRegisteredError` is now a `NormalizeError`. A hole in a sparse `values` array now reads as a missing value, as the `null` of a JSON spec does, where it threw `Cannot read properties of undefined`. An array of holes only still throws.
