### Changed / may need action

- A metric stack (`grid` with `options.stack`) now draws on a fixed canvas that is shorter than its default content height. Before, the default plot heights (200, 150 and 130 px) only grew, so a 16:9 slide of 1184 x 528 px was refused with a floor of 1263 x 867 px. Now the default plot heights shrink to each panel's readout floor. When that is still too short, the readout puts the unit beside the name, the headline and span on one line, and the panels sit 10 px apart. The refusal states the lowest height that draws. A canvas that already drew keeps its look, and an authored `stack.heights` or `rows` is never shrunk. To bring back the old look on a short canvas, set the old defaults: `{"options": {"stack": {"heights": [200, 150, 130]}}}` (use 150 for a stacked column panel and 200 for a single column panel, 130 for a line panel).
