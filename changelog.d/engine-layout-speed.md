### Changed

- Charts lay out faster on the first draw and across themes, with maps showing the largest gains by chart type. Drawings, warnings and returned sizes are unchanged. On a quiet Mac, a source benchmark against version 0.61.0 used one 878 px example of each of 36 chart types across ten theme presets, with a fresh process for each example. With font tables passed by the host, the first layout went from 95.24 ms to 69.32 ms and the mean per layout from 39.85 ms to 26.15 ms. With bundled font metrics, the first layout went from 88.24 ms to 68.93 ms and the mean per layout from 33.24 ms to 25.98 ms. With host font tables, stacked columns with staircase category labels went from 480.3 ms to 134.8 ms on the first layout and from 365.0 ms to 65.7 ms per layout across themes. The mean per layout with host font tables went from 45.2 ms to 22.3 ms for a Gantt chart with status and from 88.5 ms to 62.4 ms for a grid of column and line panels with a shared value axis. With host font tables, the mean first layout for five maps at 878 px went from 306.1 ms to 118.3 ms (413.1 ms to 189.3 ms for a US map by state), the mean per layout across themes went from 179.3 ms to 48.1 ms (251.8 ms to 85.7 ms for the US map by state), and `measure` on a map without a size went from 3,077.1 ms to 813.5 ms per call on average.
