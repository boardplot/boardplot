### Changed / may need action

- `labels: false` no longer takes the only scale of a chart with it. A histogram keeps its bin edges and drops only the counts. A bullet chart that names its bands keeps the band names above each band and the band-edge numbers under it, as `bandKey: 'row'` draws them with labels on. A pyramid draws a value axis under each pane while their value labels are off, so the bars read as numbers. Where a pinned height fits the rows but not the axis, the chart draws without the axis and warns `value-axis-dropped` with the height that keeps it. To bring back the old look of a histogram, set `labels: { point: false, category: false }`. To bring back the old look of a bullet chart, set `bandKey: 'labels'`. A pyramid has no `labels.tick` option, so its axis cannot be turned off.
