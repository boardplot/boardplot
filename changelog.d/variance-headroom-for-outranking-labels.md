### Fixed

- An integrated variance chart with a fixed height no longer drops two large variances while a smaller one keeps its value when the seat above the neighbouring columns runs into the key. At 432 × 396 pt with 12 long category names, +22.6 and −17.2 had no label while +8.1 kept its own. The chart reserves one row for values above its tallest column. When a larger variance finds no seat in that row and the seat above it would cut into the key or subtitle, the chart now lays out again with one more value row on that side (above the columns, or below them for a variance under the baseline). The columns get that much shorter. The chart keeps this layout only when it seats at least one of these values and the canvas still meets the chart's size floor. A chart with an automatic height is unchanged: it still grows its canvas for a hidden value. Old look: these values were only listed in the notes, and the columns kept the full plot height. There is no option to bring the old look back: it only ever hid labels.
