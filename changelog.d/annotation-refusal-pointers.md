### Fixed

- A refusal about one annotation points at the annotation the author wrote. Before, a chart that does not draw some annotation kinds counted the index after it dropped them, so a scatter with `[indicator100, valueLine -1]` on a log axis returned `/annotations/0` and the indicator. A list under `options.annotations` was pointed at as the root list, and several line, event and Gantt refusals had no pointer. The path, the display path and the message now name the same entry in its own list (`/options/annotations/1`, "options.annotations[1]"). A grid panel's annotation refusal points into `data.panels[i]`. The `x-cagr-unsupported` and butterfly `delta-column-covers-annotation` warnings point at the annotation the same way. An annotation the engine adds has no pointer.
