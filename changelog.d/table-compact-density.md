### Changed

- A table at `density: 'compact'` is now clearly denser than at `'regular'`. Compact keeps half of each row's regular air, rounded down. Before, it took 1 px off the air above and below each row, so a switch from regular to compact moved a table by about 3 %. A top-level or group row now takes 3 px above and below its line box instead of 6 px (regular 7 px), a sub row 2 px instead of 3 px (regular 4 px), a deeper row 1 px instead of 2 px (regular 3 px), the total row 4 px instead of 7 px (regular 8 px), and a theme's `table.rows.pad` of 3 px gives 1 px instead of 2 px. A 29-row table that took 1,125 px in regular took 1,067 px in compact and now takes 933 px. Type, column heads, cell air and column gaps keep their size, and `'regular'`, `'relaxed'` and the cohort densities draw as before. The SVG and the React table change alike. A table that does not fit its size and falls back to compact spacing takes these rows too, so some tables that were refused at a small fixed size now draw. The new theme token `table.compactStep` sets the px that compact takes off each side of a row instead. The patch `{ "table": { "compactStep": 1 } }` brings back the old look.
