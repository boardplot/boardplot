### Fixed

- A chart sent beside a root `version` no longer gets patches that delete it. The refusal now names only `version` and its fix removes only that key, so applying it leaves a chart that draws. A top-level `title`, `subtitle`, `unit` or `source` string beside a chart now gets a fix that moves it into `options` instead of a remove when the chart type's options list that key and the moved chart draws, which the CLI checks by laying it out at the width, height and target of the call, or measuring it for measure (`diagram` and `creative` take no `unit`, and a `combo` with series units or a share `pyramid` refuses one, so theirs is removed), so a repair loop keeps the title and the unit. Any other key a chart does not take, such as `$schema`, `width` or `foo`, keeps the fix that removes it, and the fixed chart draws. `BoardplotChart` and `parseChartSpec` cannot lay a chart out, so they offer the fix that removes the key.
