### Changed

- Render warnings are shorter, and two frequent layout checks no longer ask for a review. `height-off-ladder` (an authored height between the standard height steps) is now `advice`, was `warn`, with a shorter message. `dead-band` (an empty band on the canvas) is now `advice`, was `warn`; it suggests removing a margin only where the spec sets one on that edge. `height-off-ladder:row-driven` (`info`) is no longer reported: a type whose height comes from its rows has no standard step. `values-in-note` keeps `info` and states the count; each value is now only in `detail.values`, no longer also in `message`. A finding without an expectation of its own no longer copies its `suggest` or `message` into `expected.condition`; `expected` is then `{}`. The MCP server returns `advice` once per code per session, so these two checks now follow that rule too, and `render --quiet` no longer prints them.
