### Fixed

- `render` and `measure` now return on some grids with `anchors.baselines` where they did not return or the Node process crashed, such as a grid whose panels are stacked in one column. The size search of a refused layout follows the size that each refusal asks for. It now stops once that size grows past a bound set from the first refusal and the frame, and refuses the grid with `label-collision`. Before, `measure` also named a minimum height from about 15,000 px to 2 × 10^47 px on some of these grids, where the chart does not draw either. A `measure` refusal for a reason other than size now names a minimum height above the refused frame only where a layout of the chart draws at that height. Otherwise it names the frame height, or the chart type's declared minimum height when that is taller. Some grids with `anchors.baselines` are not fixed: on some, `render` and `measure` still run out of memory, and others are refused with `size-below-floor` and a minimum height of about 10^11 px, where the chart does not draw either.
