### Fixed

- `render` and `measure` return for a grid whose height floor grows with its frame, such as a grid with `anchors.baselines` on panels stacked in one column. Both refuse with `label-collision`. Before, `render` or `measure` never returned or ran out of memory on some of these specs. On others `render` refused with `size-below-floor`, and `measure` named a minimum height from about 15,000 px to 2 × 10^47 px, where the chart does not draw either. A `measure` refusal for a reason other than size now names a minimum height above the refused frame only where a layout of the chart draws at that height. Otherwise it names the frame height, or the chart type's declared minimum height when that is taller.
