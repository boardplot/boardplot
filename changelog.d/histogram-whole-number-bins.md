### Changed / may need action

- A histogram of whole numbers now draws one bin per value. When every observation is a whole number and the bin width is 1 (`bins: 'auto'`, or `bins: { width: 1 }` without an anchor), the first edge sits at the smallest value minus 0.5. Each bar then holds one value and the value prints under the bar centre. Before, the edges sat on the whole numbers and the closed last bin held two values: values 0 to 4 with counts 20, 25, 24, 25 and 26 drew four bars and a false spike of 51. An `auto` width that snaps below 1 on whole numbers now rises to 1, so no bin falls between two values. The default footer reads "One bin per value · n = 120.", and `derived.binning.perValue` is `true`. To bring back the old look, set `bins: { width: 1, anchor: <smallest value> }`. For an `auto` width that was below 1, set `bins: { width: <old width> }`, for example `bins: { width: 0.5 }`.
