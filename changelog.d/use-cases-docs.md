### Added

- The docs page `docs/use-cases.md` gives one recipe for each place a chart goes: slides and Word reports, an HTML report or wiki page, a React or Next.js dashboard, a scheduled report and a report an agent writes. Each recipe names the route, the command or component and the pitfalls (fonts, transparent background, PNG scale, target). The README, the manual, `llms.txt`, the npm package and the offline plugin ZIP link or carry it, and the chart skill says how to deliver a chart to each destination.
