### Changed / may need action

- A bullet chart now prints every actual value right-aligned in one column right of the bands. Beside the Target and Gap-to-target columns, the column has the head Actual (German Ist, `strings.actualColumn`). Before, a value sat inside its bar end when every value fitted there, else outside the last band, flush left. Rows that name their bands (`bandKey: 'row'`) put a value just past its own bar end where the target tick left room, else outside the band. So one row's value could sit at its bar end and the next row's value past the band, and values of different widths (116 and 97.7) did not line up on their last digit. Stacked cards right-align the value at the card's right edge too. A negative row keeps no room left of its bar for a value. There is no option for the old seats. The nearest look is `{ "labels": { "point": false } }`, which takes the values off the page.
- A box chart whose rows are too low for a median over its box (row pitch under the value-label height + 19 px) now prints every median right-aligned in one column left of n, under the head Median. Before, such a median moved to the whisker end, left of the whisker or beside an outlier dot, where it read as that mark's value. Where no seat was free, the median went to a note the page does not show. For example, 12 rows on an 888 × 396 pt slide lost all 12 medians on a min-max chart. The n beside dense rows keeps no padding, so every n prints. Rows tall enough keep the median over the box, and `boxValues: 'all'` keeps its seats. There is no option for the old seats. The nearest look is a taller frame (row pitch at least the value-label height + 19 px) or `{ "labels": { "point": false } }`.
