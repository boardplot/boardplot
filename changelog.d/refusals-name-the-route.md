### Changed

- Four refusals now name the setting that does the job. A dimswitch without its range or prior period names `options.columnVisibility` to hide that column. An invalid table status names `{ state: 'na' }` for a status that cannot be decided. Rows without a series column say to add one with the same series name on every row. An unknown theme name lists the themes whose name holds it first, so `dark` names `bridge-dark`, `standard-dark` and `notation-dark`.
