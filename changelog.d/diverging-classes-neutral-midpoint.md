### Changed / may need action

- Diverging maps with `classes` no longer give a value on the midpoint a side. An odd class count (3, 5 or 7) now mirrors its breaks around the midpoint when values sit on both sides, so the centre class holds the midpoint and takes the existing midpoint grey. The end classes print open-ended, for example "Under −10%" and "+10% and above". Example: a 5-class tilemap of −12 % to +12 % against plan changes from breaks `−10, −5, 0, 5` (three red classes, two green classes, 0 % painted green) to `−10, −5, 5, 10` (two red, one grey, two green). An even class count keeps its break on the midpoint. A value exactly on it now takes the midpoint grey with its own key entry, for example "0%", and the class above it reads "Over 0% to under +5%". Applies to `tilemap` and `choropleth`. Explicit `steps` paint as declared.
  Old look for 5 classes: set the old breaks as steps, for example `"steps": [-10, -5, 0, 5]`. This restores the old breaks and colours. The end classes print open-ended. 3 and 7 classes, and the grey for a value on an even-count midpoint, have no option that restores the old look.
