### Added

- Rows for `table` (alias `tbl`): `boardplot render` and `boardplot measure` with `--rows`, `boardplot_render` and `boardplot_measure` with `rows` or `rowsFile`, and `specFromRows` from `boardplot/rows` fill `data.rows` from a flat table, one source row per table row. The spec's `data.columns` declares the columns, with no inference from the rows: each `value`, `text`, `status` or `date` column reads the source field named like its id, and `computed` and `encoding` columns keep their definitions. Two optional column roles: `label` fills the row label that the `rowLabel` column shows, and the new role `id` fills the row id (default `row-1`, `row-2`, ...), as in `--columns label=region,id=code`. Rows keep source order. A spec row with the same id keeps its authored fields, such as `role`, `parentId`, `calc` or `format`. A table column with no source field, text that a value column cannot read as a number, a boolean cell, an empty or repeated row id and a `valueKind` other than `number` are refused with the source row and field; a refusal or warning of the table engine about a source cell, such as a status it refuses, names the source row and field too. A repeated spec row id, a nested spec row with another `parentId`, and a drawn row whose `parentId` or `calc` names a spec row that no source row provides are refused at the spec field.
