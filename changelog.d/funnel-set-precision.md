### Changed

- A funnel prints its segment values and stage totals as one set: one magnitude and one decimal count, so `1.18B · 0.59B · 0.29B · 0.14B` instead of `1.18B · 590M · 290M · 140M`, and `5.0 · 1.0 · 0.6` instead of `5 · 1 · 0.6`. The step rates and, on the centered funnel, the cumulative rates are sets of their own: `9.7% · 30.6% · 100.0%` instead of `9.7% · 31% · 100%`. Hover text and the description print the same text as the label. No option or theme patch brings back the old look for every chart, and no input brings back the old rate texts. For values, a cell format per value restores the old text exactly, for example `"values": [{ "number": 1180000000, "format": "1.23B" }, { "number": 590000000, "format": "1M" }]`. A chart format of `"1M"` brings back one magnitude per label, at that example's decimals (`1.2B · 590M`).
