### Changed / may need action

- A long row name no longer takes the whole widened name column. A name that two lines cannot hold in the usual name column now takes the narrowest width, up to the widened budget, that holds it in two lines. Before, it took the full widened budget and stayed on one line, so one long name set the width of the whole column. On a half-width bar chart the bars now start at 35% of the width, not 47%, and every value prints where 17 of 48 went to a note. Likert, bar, dot, heatmap and the other charts with a name column follow the same rule. Old look: no setting brings back the full-width one-line names. Shorten a name or add a line break (`\n`) to set where it wraps.
- A pie with its labels in two columns wraps each name to the column before it reserves room for the labels. A name takes at most two lines, in a column of 30% of the plot width, or up to 40% when two lines need it. Before, the reserve measured every name on one line, so on a half-width slide or a 480 px card with long names the pie fell to 40 px. When the ring of labels round the pie cannot seat every label, the labels now sit in two columns beside the pie, each at the height of its slice, with a straight leader. Old look: no setting brings back the unwrapped reserve.
