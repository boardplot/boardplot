### Fixed

- A warning that a grid passes on from a panel now points into that panel (`/data/panels/<i>/...`) or at a grid option the panel takes from the grid, and its patch applies there. Where no field of the authored spec holds the value the panel used, the warning carries no pointer and no patch. A panel's size patch (`table-tight-spacing`, `size-below-floor` and the other size findings) is no longer given as a patch of the whole grid's size: the suggestion names the panel and the size it needs. Each passed-on warning names its panel in `detail.panelId`. `measure` and render now give the same pointer and patch for these warnings, and `measure` no longer searches a grid size for a panel's `plot-under-floor`. The same rule holds for the inner chart of `pareto`, `likert`, `pvm`, `histogram`, `cohort` and `dimswitch`.
