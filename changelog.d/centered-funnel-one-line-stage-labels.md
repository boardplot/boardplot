### Changed / may need action

- A centered funnel whose bands are too short for a stage name over its value now prints the name and the value on one line in the outside column: the name flush left, the value flush right. Before, such a size was refused with `size-below-floor`; an 8-stage centered funnel at 888 x 396 pt needed 447 pt of height. The row floor is now one line per stage, so `measure` reports a lower `minHeight`, `measuredMinHeight` and `comfortableHeight` for centered funnels (for example 381 to 326 px for a 6-stage funnel at 720 px). Every size that drew before draws the same: labels stay two lines while each band holds them, inside the funnel or beside it. There is no patch for the old look, because the old look at these sizes was a refusal. To keep two-line labels, give the chart at least the old height, which the size error used to name.
