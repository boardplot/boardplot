### Changed

- The hover card of a `grid` metric stack no longer prints a "Category state" row on a category in the default state. A card read "Started / Jan / 800 cases per month / Category state: mature". It now reads "Started / Jan / 800 cases per month". The keyboard card and the accessible text drop the row too. No setting brings the row back. A category in a declared state, such as a running period (`partial`) or a maturing period, keeps its row.
