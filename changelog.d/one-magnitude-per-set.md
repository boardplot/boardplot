### Changed

- A sankey (its node and link values), each pane of a butterfly and a pyramid, and a dot chart print their values at one magnitude, as the funnel does: the largest step at which the smallest value still prints as 1 or more, while the largest keeps at most four digits. So `1,505M · 935M` instead of `1.505B · 935M`, and `9,600k · 400k · −2,800k` instead of `9.6M · 400k · −2.8M`. A set that no step fits keeps one scale per label as before. Decimals and shares print as before. The value axis of a dot chart follows its labels: `−5,000k · 0 · 5,000k` instead of `−5M · 0 · 5M`. No option or theme patch brings back the old look for every chart. A chart `format` holds every label to the scale of its example, for example `"format": "1.2B"`.
