### Fixed

- A row name that wrapping, the wider gutter and the smaller type step would still cut now takes one more line when its row holds that line. Before, bar names stopped at three lines and tornado names at two, so a name printed with an ellipsis in a row that had room for another line. The same step applies to the row names of dot charts. The gutter cap stays at 45% of the plot, and a name that already fits keeps its lines.
