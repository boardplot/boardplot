### Changed / may need action

- Stacked bands now default to one ordered ramp. A `stacked-area` or `stacked100-area` line chart without a highlight, palette or series fill takes `emphasis: 'ordered'`: the first band is the lightest step and the last band the full ink. Before, each band took its own theme hue (`color.series[i]`, on the default theme `#12395E`, `#5E99C5`, `#B58629`, `#72767C`, `#6F69CC`, `#587000`, `#229B72`, `#335B83`). To bring back the old look, set the option `{ "emphasis": "none" }`. The `emphasis` option text now names the stacked variants.
- A pie now defaults to `colors: 'sequential'` at every slice count. Before, up to four slices without `topN` or `palette` took categorical hues (on the default theme navy `#12395E`, blue `#5E99C5`, ochre `#B58629` and grey `#72767C`), and five or more took the ramp. A highlight keeps its accent. To bring back the old look, set the option `{ "colors": "categorical" }`.
- Treemap groups now share one colour family by rank: the first drawn group (the largest under the default order) takes the strongest step and later groups lighter steps. The steps come from the new theme field `color.treemap`, else `color.stack`, else the first series colour stepped toward the page, decided in the theme the chart is painted in, so a dark theme takes its own ramp. Before, the groups took `color.series` in order (on the default theme `#12395E`, `#5E99C5`, `#B58629`, `#72767C`, `#6F69CC`, `#587000`, `#229B72`, `#335B83`). A group `fill` or `colorRole` and `options.palette` still win, and a treemap without groups keeps the first series colour. To bring back the old look, set the theme override `{ "color": { "treemap": <your theme's color.series list> } }`, on the default theme `{ "color": { "treemap": ["#12395E", "#5E99C5", "#B58629", "#72767C", "#6F69CC", "#587000", "#229B72", "#335B83"] } }`.
- A treemap with a `color.series` theme override and no `color.treemap` or `color.stack` override warns `stack-palette-used` where the theme's ramp, not the override, paints the groups.

### Added

- Theme field `color.treemap`: the treemap group fills by rank, 2 or more colours. The fixture `growth-rect-group-hues` shows it.
