How to use
  • Overview. One card for each chart type and variant, at the width, chart theme and locale in the toolbar. Click a card to open its chart page.
  • Chart page. The chart at all five widths (960 to 320 px), one under the other. The width filter shows one width. The settings on the left change all widths. “Back to overview” in the top bar keeps your selection and scroll position.
  • Real size. Every chart shows at its real pixel size. A row that is wider than the screen scrolls sideways.
  • Data share. The part of the chart frame that the data marks cover. It is a ranking aid, not a verdict. “Sort overview: Data share · worst first” puts the smallest plots first. Table-like types (table, bartable, dimswitch, kpi) show n/a, because their data is text.
  • Review one card. “Copy review packet” copies a review prompt with the card's ID and spec. Paste it into an AI chat and attach a screenshot of the chart.
  • Review all widths. “Copy review packet (all widths)” on the chart page copies one prompt for all five widths. It lists which widths Boardplot refused.
  • Review round. Click “Select for review” on the cards you want, then “Copy selection” in the top bar. You get one ID per line. Turn the IDs back into specs with npm run -s explorer -- --spec - (paste the list on stdin).
  • Before / after. On the chart page, “Before / after” shows each card (before), a line, and the redesign for the same card (after). To add a redesign: put the image (PNG or SVG, at the card's width) in scripts/explorer/after/, add "<card ID>": "<file name>" to scripts/explorer/after/index.json, run npm run explorer and reload the page. The card ID must match exactly, so width, chart theme, locale and settings must be the same.
